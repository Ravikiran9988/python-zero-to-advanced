## Book Overview

**Python: Zero to Advanced** is a practical, structured self-study book that guides readers from programming fundamentals to professional Python topics. It combines clear explanations, analogies, worked examples, expected outputs, assignments with solutions, guided workshops, and portfolio projects.

The book encourages active learning: write the examples yourself, predict what they will do, run and modify the code, solve the exercises independently, and then review the solutions.

## Who This Book Is For

- **Beginners** who want to learn programming and Python from the foundations.
- **Python learners** who want a more systematic understanding of the language and its ecosystem.
- **Developers in progress** who want to explore APIs, databases, automation, data analysis, machine learning, and deployment.
- **Self-learners** who benefit from structured practice, worked examples, projects, and solutions.

The book moves from introductory concepts toward advanced topics. You do not need to start with the advanced chapters; follow the sequence and build your skills step by step.

## Curriculum

The 45 chapters are organised into ten parts, followed by advanced workshops in Chapters 41–45.

### Part 1 — Programming Foundations

- Introduction to programming and Python
- Installing Python and setting up Visual Studio Code
- Your first Python program
- Variables, data types, and type conversion

### Part 2 — Core Python

- Operators and expressions
- Input and output
- Conditional statements and structural pattern matching
- Loops and repetition
- Problem-solving fundamentals and algorithms

### Part 3 — Python Data Structures

- Strings and string methods
- Lists and list comprehensions
- Tuples, sets, and dictionaries
- Slicing, unpacking, and nested data structures

### Part 4 — Functions and Code Organisation

- Functions from basic to advanced
- Arguments, return values, scope, and recursion
- Lambda functions, `map()`, `filter()`, and higher-order functions
- Modules, packages, imports, and virtual environments

### Part 5 — Object-Oriented Python

- Classes, objects, and constructors
- Encapsulation, inheritance, and polymorphism
- Abstraction, composition, and design principles
- Dunder methods, dataclasses, and properties

### Part 6 — Professional Python

- Exceptions and error handling
- File handling: text, CSV, JSON, and paths
- Iterators, generators, and decorators
- Type hints, enums, context managers, and logging

### Part 7 — Advanced Python Internals

- Python execution, objects, and memory
- Mutability, references, copying, and garbage collection
- Testing, debugging, profiling, and code quality
- Concurrency with threads, processes, and asyncio

### Part 8 — Real-World Development

- HTTP, APIs, and web services
- SQL databases and Python integration
- Web development with FastAPI
- Automation, web scraping, and command-line tools

### Part 9 — Data, AI, and Machine Learning

- NumPy, Pandas, and data analysis
- Data visualisation and statistics
- Machine learning fundamentals with scikit-learn
- LLMs, embeddings, retrieval-augmented generation (RAG), and AI applications

### Part 10 — Production and Mastery

- Security, configuration, and dependency management
- Docker, CI/CD, deployment, and monitoring
- Architecture, performance, and design patterns

### Chapters 41–45 — Advanced Workshops

The final five chapters deepen concepts introduced earlier, including the Python object model, packaging, type hints, testing, and asynchronous programming. They include lessons, assignments with solutions, guided projects, reviews, bonus practice, and workshops.

## How to Use the Book

For Chapters 1–40, the regular chapter pattern includes:

1. **Explanation:** concepts introduced in simple English with analogies and examples.
2. **Summary and practice:** key points and quick exercises.
3. **Workshop A — Walkthroughs:** programs explained line by line, including tracing tables.
4. **Workshop B — Assignments:** six tasks ranging from Easy to Hard, with solutions and explanations.
5. **Workshop C — Project:** a complete project built in stages.
6. **Extra practice:** additional drills and find-the-bug exercises in selected chapters.

Chapters 41–45 follow a slightly different order: lessons, practice assignments and solutions, a guided project, chapter review, bonus practice, and then the workshops.

**A suggested learning routine:**

1. Read the explanation and understand the concept.
2. Type the example yourself instead of only copying and pasting.
3. Predict the output before running the program.
4. Change the code and observe what happens.
5. Attempt the assignments before checking their solutions.
6. Build the chapter project and keep your work organised.

## 28-Week Study Plan

The book includes a 28-week study plan based on approximately 30–60 minutes of regular study per day. The schedule below covers Chapters 1–40.

| Weeks | Chapters | Focus |
|---|---|---|
| 1–2 | 1–4 | Setup, first programs, variables, and types |
| 3–4 | 5–9 | Operators, input, decisions, loops, and problem solving |
| 5–6 | 10–13 | Strings and data structures |
| 7–8 | 14–17 | Functions, recursion, modules, and packages |
| 9–11 | 18–21 | Object-oriented programming |
| 12–14 | 22–25 | Errors, files, generators, decorators, typing, and logging |
| 15–17 | 26–29 | Python internals, testing, and concurrency |
| 18–21 | 30–33 | APIs, SQL, FastAPI, and automation |
| 22–25 | 34–37 | Data analysis, charts, machine learning, and AI |
| 26–28 | 38–40 | Security, deployment, and architecture |

Chapters 41–45 are an additional advanced block and can be studied after the related topics.

## Technical Notes and Verification

Please read these notes alongside the examples:

- The examples target **Python 3.12**; most should also run on Python 3.11.
- Appendix G's ten portfolio projects and the workshops in Chapters 41–45 were run on Python 3.12.3.
- Chapters 1–40 and the lessons and assignments in Chapters 41–45 were reviewed by reading; most displayed outputs in those sections were worked out from the code rather than re-run for this edition.
- Some examples require an internet connection, an account, third-party packages, or separate tools. Not every example can be executed in the book's verification environment.
- FastAPI, Pydantic, httpx2, and pytest were not installed in the stated verification environment; code requiring them was not run there.
- Code examples are educational and are not represented as production-ready. Review and test code, security, performance, and licensing before using it in real systems.

When library behaviour or a version detail differs, consult the relevant official documentation.
